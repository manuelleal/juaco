## 13. Glosario

**Idea principal.** Todos los términos y siglas del proyecto, en orden alfabético, con una definición de una o dos frases. Entre paréntesis, la sección donde se explica con más detalle.

| Término | Qué significa |
|---|---|
| **A** | Letra "comida": al morderla da +0.8 de energía. (2) |
| **A+C, mundo** | Número medio de objetos buenos (comida más agua) presentes en el mundo durante una corrida. Si un organismo lo deja bajo, "pela" el mundo. (5) |
| **AGI** | Inteligencia artificial general, por su sigla en inglés. Es la dirección del proyecto, no algo que se afirme. Las reglas prohíben declararla. (12) |
| **Ag** | Nivel de agua del cuerpo. Cuando llega a cero, muere de sed. (3) |
| **Alejo** | Segundo experimento del director, separado de JUACO: probar si una célula con regla local sirve junto a modelos convencionales. (11) |
| **Ancla** | Fragmento exacto de texto en un programa donde se inserta código nuevo. "Construir por anclas": modificar un organismo con un programa que inserta líneas, sin editar el original. (6) |
| **Antípoda** | El punto opuesto del anillo. Los controles de la Escalera leen o siembran en la casilla antípoda: mismo esfuerzo, lugar equivocado. (7) |
| **Arnés de identidad** | Batería de comprobaciones de que, con el módulo nuevo apagado, el organismo es idéntico bit a bit al anterior. (6) |
| **Auditor** | Agente de sólo lectura que revisa antes y recalcula después. No edita ni corre experimentos grandes. (6) |
| **B** | Letra "veneno": al morderla quita 0.4 de energía. (2) |
| **Bien público** | Algo que cuesta a quien lo hace y beneficia a todos. La hipótesis, sin medir, de que la limpieza lo es. (9) |
| **Bin** | Casilla. La memoria de lugar divide el anillo en 30. (4) |
| **Bit a bit** | Exactamente igual, hasta el último dígito. (6) |
| **BLOQUES** | Experimento del 28 de septiembre: genoma de reglas armables; la selección fijó un órgano de rechazo. (7) |
| **Brazo** | Cada una de las variantes que se comparan en un experimento (candidato, control, base). |
| **C** | Letra "agua": al morderla da +0.8 de agua. (2) |
| **c_e** | Costo de escribir en la pizarra: 0.01 de energía. (4) |
| **Cadena** | En los experimentos de selección, una secuencia de pasajes encadenados. Se corren 20 cadenas. (4) |
| **Cámara continua** | Regla del aparato de selección: el reemplazo de un linaje extinto copia, con una mutación, los genes de otro linaje vivo. (4) |
| **Carga mutacional** | El daño acumulado por mutaciones que empeoran. |
| **Carro** | El programa que decide por un linaje: su "cerebro". El nombre viene de la carrera de escuderías. (3) |
| **Carrera de escuderías** | Competencia del 22 de septiembre en que equipos de agentes escribieron cada uno su organismo para la misma pista. De ahí salió O1. |
| **Casi inmortal** | Linaje con menos de cinco muertes en una corrida. No se evalúa. (5) |
| **Celda** | Cada posición del anillo. |
| **Celda retenida** | Combinación de condiciones que se le oculta al organismo durante la crianza para preguntarle después por ella (P8). (7) |
| **Clon, clonal** | Copias con el mismo programa. "Monocultivo" es una pista de clones. |
| **Cola** | La fila donde esperan los hijos ya paridos hasta que muere el padre. Admite hasta 200. (3) |
| **Commit** | Guardar un cambio en el historial del repositorio, con fecha y huella. |
| **COMP, COMP2** | Las dos versiones del módulo de P8. COMP no se declara; COMP2 funciona con reservas. (7) |
| **COMPONE** | Perilla de P8: si el recuerdo del sitio se suma también a letras mixtas, y con qué compuerta. (4) |
| **Congelado** | Archivo que no se puede editar; lo protege un manifiesto de huellas. |
| **Consigna** | El nivel hasta el cual el cuerpo sigue comiendo lo bueno: umbral de parto más MARGEN. (3) |
| **Control** | El rival de un experimento. "Que puede ganar": diseñado con el mismo esfuerzo y el contenido equivocado. (6) |
| **Coordinador** | La sesión principal de inteligencia artificial: decide, corre los experimentos grandes, registra. (6) |
| **Cruzar** | Un linaje cruza si tiene R0 real de 0.90 o más, cinco muertes o más y ningún fundador después del paso 10 000. (5) |
| **D (letra)** | Letra "sal": al morderla quita 0.4 de agua. (2) |
| **D (medida de P8)** | Probabilidad de morder la E dentro del oasis menos probabilidad de morderla fuera. (5) |
| **D0** | Perilla de O1: suaviza la distancia en el puntaje. Vale 3. (4) |
| **δ (delta)** | Sesgo a la pérdida: cada mutación resta además 0.01. (4) |
| **dens** | Fracción de lo repuesto que nace dentro del oasis: 0.5. (4) |
| **Deriva** | Cambio de un gen por puro azar, sin que le sirva de nada al organismo. Es el control de los experimentos de selección. |
| **Diseño** | Lo que escribió un ingeniero. Lo contrario de selección. (7) |
| **Dote** | Lo que el padre paga y con lo que nace el hijo: 0.6 de energía y 0.6 de agua. (3) |
| **E (letra)** | "Sal dulce": +0.3 de energía y −0.1 de agua. Sólo en P8. (2) |
| **E (nivel)** | Nivel de energía del cuerpo. Cuando llega a cero, muere de hambre. (3) |
| **ECO** | El otro mundo del proyecto: con población real y comida que entra a ritmo fijo. (2) |
| **ECO_SEL** | Experimento del 28 de septiembre: la selección sube la capacidad de carga en ECO. (7) |
| **EMA** | Promedio que le da más peso a lo reciente. La memoria de lugar se actualiza así. |
| **En el umbral** | Resultado a una semilla del corte. Obliga a réplica. (5) |
| **Enmienda** | Cambio escrito a una regla ya fijada. Lleva número de ERR. (6) |
| **Epistasis** | Cuando el efecto de un gen depende de qué otros genes hay. |
| **ERR** | Error numerado del proyecto. (6) |
| **Escalera** | Línea de trabajo desde el 30 de septiembre: agregarle a O1 capacidades por diseño, peldaño a peldaño, en mundos que las pagan. (7) |
| **Establecido** | Linaje sin fundadores después del paso 10 000. (5) |
| **Evaluable** | Linaje con cinco muertes o más. (5) |
| **Exploratorio** | Lo que se prueba sin protocolo completo. No se declara. (11) |
| **extra** | Lo que el oasis añade a comida y agua: +0.8 en la otra necesidad. (2) |
| **F0** | La medición del reloj mutacional. (10) |
| **F1 (arranque en frío)** | Resultado del 25 de septiembre en ECO: un linaje se sostiene un millón de pasos sin criadero. (7) |
| **Fable, Opus, Sonnet, Haiku** | Nombres de los modelos de inteligencia artificial que hacen de coordinador, creadores, auditores y probadores. |
| **FABRICA** | El organismo de referencia de la carrera: el de la fase 9 puesto en la pista. "De fábrica" también significa "con los valores originales". |
| **Fundador** | Cuerpo que el mundo pone cuando un linaje se extingue. Cada uno cuenta una extinción. (2) |
| **Fundador limpio** | Regla por la cual ese cuerpo nace sin nada de la memoria del linaje. Origen del candidato ERR-191. (2, 9) |
| **Gemelo** | Versión compilada, más rápida, de un programa, que debe dar resultados idénticos. |
| **Gen** | Número que cada cuerpo lleva, hereda su hijo y puede mutar. |
| **Genoma** | El conjunto de genes de un cuerpo. "Monomórfico": todos con el mismo. |
| **GV** | Gen de la ganancia del viaje al sitio recordado. Es el que la selección sube. (4) |
| **GW** | Gen del peso del recuerdo del sitio en el valor de un bocado. La selección no lo sube. (4) |
| **H-1** | Nombre del umbral R0 de 0.90 o más: "el muro". (9) |
| **Hamburguesa** | Prototipo exploratorio: modelo congelado más células de memoria viva. (11) |
| **Hueco** | Regla de O1: sin nada a qué ir, colocarse en el mayor espacio vacío entre cuerpos. (3) |
| **Humo** | Corrida corta de comprobación. No es dato. (6) |
| **Juez** | El programa que calcula las medidas desde la física de la pista. (5) |
| **Junta** | Reunión de varios agentes investigadores para diagnosticar. Sus conclusiones son hipótesis de trabajo. |
| **K (letra)** | "La llave": no da ni quita. Sólo en el intento de P9. (2) |
| **K (medida)** | Capacidad de carga en ECO: promedio de cuerpos vivos en la segunda mitad. (5) |
| **L** | Largo del anillo: 360 con nueve linajes. (2) |
| **Latencia** | Pasos desde una mudanza hasta el primer bocado en el oasis nuevo. (5) |
| **Letra (del preregistro)** | La regla de decisión tal como quedó escrita. "Por la letra": aplicándola sin interpretar. (6) |
| **LG2** | Perilla de P8: la tabla por letra no aprende donde el sitio ya da de más. (4) |
| **LG_ETA, LG_MIN, LG_NB** | Perillas de la memoria de lugar: velocidad (0.5), umbral (0.05) y número de casillas (30). (4) |
| **Limpieza** | Regla de O1: morder algo malo a propósito cuando no hay nada útil. Con cautela por el fundador limpio. (3, 9) |
| **Linaje** | Cadena de cuerpos que se suceden, con un mismo carro. Un cuerpo vivo a la vez. (2) |
| **Linaje-semilla** | Un linaje en una corrida. 9 por 20 = 180. (5) |
| **Mapa del muro** | Sonda del 1 de octubre: O1 con valores fijos de sus perillas en la pista vieja. Exploratorio. (9) |
| **MARGEN** | Perilla de O1: cuánto por encima del umbral de parto sigue comiendo. Vale 0.25. (4) |
| **Mayoría** | Cinco o más de los nueve linajes de una corrida cruzan. (5) |
| **Memoria de lugar** | Módulo de P1: una libreta de lo que cada sitio dio de más. (3, 7) |
| **Moneda** | En qué se le paga a un linaje para que sus genes pasen: estar vivo, haber durado. (8) |
| **Monocultivo** | Pista con nueve linajes del mismo carro. |
| **Mundo con oasis** | La pista más un tramo rico, pobreza fuera y vista corta. (2) |
| **Muro** | El umbral de sostenerse en la pista vieja, y la dificultad de que la selección llegue a él sola. (9) |
| **Mutación** | Cambio pequeño al azar en un gen al nacer. |
| **Neutro** | Brazo de control donde los genes mutan y se heredan pero ningún cuerpo los usa. (4) |
| **Nivel (del brief)** | Los escalones del plan original del proyecto, con un porcentaje de avance que fija el director. |
| **nl** | Contador de mordidas por casilla en la memoria de lugar. Marca "sitio ya vivido". |
| **nobj** | Número de objetos del mundo: 36 con nueve linajes. (2) |
| **Nulo** | Lo que saldría por azar si la idea fuera falsa. (6) |
| **O1** | El organismo que cruza, escrito por la escudería O1. Base de la Escalera. (3) |
| **o1_evo** | Experimento: O1 con cuatro perillas heredables. La selección lo conserva, no lo mejora. (8) |
| **O1 libre** | Experimento de una sesión paralela: O1 con cuatro poderes apagados. Bloque NO. (8) |
| **Oasis** | Tramo del 10 % del anillo donde comida y agua valen más. (2) |
| **Olvido (del mundo)** | El mundo retira un objeto al azar de vez en cuando. (2) |
| **Oráculo** | Control al que se le da la respuesta correcta. Mide el techo posible. |
| **Órgano** | En BLOQUES, una regla heredable fijada por selección. No más que eso. (7) |
| **P0 … P10** | Los peldaños de la Escalera. P1 memoria de lugar; P2 colonia; P7 señal; P8 celda retenida; P9 planear; P10 ir a lo menos visitado. (7, 8) |
| **Pareado** | Comparar dos organismos con la misma semilla. (5) |
| **Pasaje** | Una corrida dentro de una cadena: lo que queda vivo al final siembra la siguiente. (4) |
| **Paso** | Un tic del reloj del mundo. (2) |
| **Pelar el mundo** | Dejarlo con poca comida y agua presentes. |
| **PEN_OTRO** | Perilla de O1: descuento a un objeto que otro cuerpo tiene más cerca. Vale 0.35. (4) |
| **Perilla** | Número del código que se pudo poner distinto. (4) |
| **Perillas (experimento)** | Resultado del 1 de octubre: la selección sube GV desde cero. (7) |
| **PG_OLVIDO** | Perilla de P10: 1 % de olvido por paso con necesidad y sin ver nada. (4) |
| **PISA** | Variante de una línea: lo leído puede pisar un recuerdo propio que ya no vale. (4, 7) |
| **PISO** | Perilla de O1: nivel mínimo que la limpieza respeta. Vale 0.2. (4) |
| **Pista** | El mundo de la carrera. "Pista vieja": sin oasis. "Pista mixta": con carros distintos. (2) |
| **Pizarra** | Tablero público de la pista: 16 anotaciones de hasta 8 números. (2) |
| **pobre** | Factor que reduce comida y agua fuera del oasis: 0.5. (2) |
| **Polizón** | El que se beneficia de un bien público sin pagarlo. (9) |
| **Pool** | Correr varios procesos a la vez. Sólo lo hace el coordinador. |
| **Preregistro** | Documento escrito y guardado antes de correr. (6) |
| **Profundidad mutacional** | Número de mutaciones en la ascendencia de un genoma. (10) |
| **Promotor** | El interruptor de un módulo. Apagado, deja el organismo anterior. |
| **PRUEBA** | Perilla de O1: nivel mínimo para probar una letra desconocida. Vale 0.5. (4) |
| **PS_LEE** | Perilla del aparato de selección: si los cuerpos usan o no sus genes. (4) |
| **Puerta** | Cada condición numérica de una regla de decisión. |
| **Quimiostato** | Aparato de laboratorio que alimenta un cultivo a ritmo fijo. En ECO, la comida entra así. |
| **R0** | Medida de si un linaje se repone. "R0 real": nacimientos reales entre muertes más uno. (5) |
| **Ráfaga** | Modo de trabajo rápido: pruebas cortas de un proceso. Nada se declara. |

| **Réplica** | Repetición con semillas nuevas y la misma regla. (5) |

| **SN_CADA, SN_UMBRAL, SN_W** | Perillas de la señal: cada cuánto emite (100), recuerdo mínimo para emitir (0.3), peso de lo oído (1.0). (4) |
