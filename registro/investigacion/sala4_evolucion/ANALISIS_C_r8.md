## ERRORES DISEÑO DESTAPADOS

### 2. **Asimetría canal TX/RX: Lurkers cargan menos riesgo**

- **Reparación R9:** Cuota mínima emisión: cada célula TX ≥1 patrón/ronda si M3 actualizado

- **Error concreto:** Larva_rosa +0.1 (C9) vs +0.25 (C3) vs +0.68 (C5); no convergencia

### 4. **Saciedad binaria bloquea reproducción**
